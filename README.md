### Selected Work

**Serverless Image Processing Pipeline**  
`S3` · `Lambda` · `IAM` · `CloudWatch`  
Fully event-driven pipeline. Images are processed and metadata stored without any idle compute. Designed with tight IAM controls and monitoring.

**Automated Incident Response**  
`CloudWatch` · `EventBridge` · `Lambda` · `Systems Manager`  
Detects HTTPD service failure on EC2 and restores the service automatically. End-to-end recovery path tested with zero manual intervention.

**Three-Tier Architecture on AWS**  
`VPC` · `ALB` · `Auto Scaling` · `RDS`  
Production-style multi-AZ design with clear separation of web, application and database layers. Focus on network isolation and scalability.
