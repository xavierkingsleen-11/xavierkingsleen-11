# Xavier Kingsleen — SOC Analyst GitHub Profile

This package is designed for the profile repository:

`xavierkingsleen-11/xavierkingsleen-11`

## Upload

1. Open the profile repository on GitHub.
2. Upload **all files and folders** from this package, keeping the structure unchanged.
3. Make sure `README.md` is in the repository root.
4. Keep the `assets/` folder and `.github/workflows/snake.yml` exactly where they are.
5. If the repository already contains an older `README.md`, replace it with this one.
6. Commit the changes.

## Contribution Snake

The workflow generates the live snake into the `output` branch. The README has a local preview fallback, so the contribution section is not dependent on the first workflow run.

## Important

- The pixel avatar is a generated pixel-art representation based on the provided portrait; the original photo is not included in the package.
- GitHub activity/stat cards use live external GitHub-stat services and can change as those services update.
- No fabricated GitHub numbers are hard-coded into the README.
